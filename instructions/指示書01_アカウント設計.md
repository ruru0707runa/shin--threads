# 指示書01 アカウント設計

目的: Threadsアカウントの「勝敗を決める部分」を、投稿を1本書く前に確定させる。

## 手順

### STEP1 ジャンル選定
収益モデル別に判断軸を変える。
- アフィリ中心: 単価が低い前提で母数勝負。バズりやすく多くの人に当てはまるジャンルを選ぶ。案件単価の目安は1件5,000円以上ある分野を優先。低単価しかない分野は、多数商品×複数購入が見込める場合のみ可。
- 低単価商品（〜10万円買い切り）中心: 本人に興味があり、1万円以上の商品が成立するジャンル。
- 高単価商品（10万円以上）中心: 専門知識があり、バズらなくても確実に存在する深い悩みがあるジャンル。悩みは健康・キャリアと将来・人間関係・お金の系統で探す。
- 除外: 母数（リーチの上限）が小さく、アフィリも商品販売も成立しないジャンル。
出力: 候補ジャンルを最大3つ、各候補について「母数／単価／本人の興味と経験／競合の強さ」を表で比較し、推奨を1つに絞る。

### STEP2 市場リサーチ（最低10件の競合・AIリサーチで実施）
収集と一次分析はAIエージェントに実行させる（詳細手順は指示書02）。シートは手作業の記録用ではなく、AIへの出力様式として使う。深さの基準は「手作業なら最低10時間相当」。AIの結果が浅い場合は、不足を明示させて追加調査を依頼する。
- 対象: 伸びているアカウント10件以上（Threads単体で伸びているものを優先。インスタ流入主体のものは除外）
- 各競合の収集項目: ポジショニング（絞り方・掛け算の要素）、コンセプト、強み・実績、発信内容のパターン、マネタイズ方法（プロフィールと固定投稿から推定）、開始時期（初投稿日や連携Instagramの参加時期から推定し、根拠を併記）、伸び方の特徴（急増のきっかけが分かれば）
- 取得できなかった項目は「未確認」と明記させる。推測で埋めさせない。
- 最後に「自分の商品の仮設計」: タイトル案、テーマ、価格帯、ターゲット、強み、弱み

### STEP3 ベンチマーク決定
- 運用ベンチマーク（運用全体の手本）1件
- 投稿スタイルベンチマーク（文体・構成の手本）1件。別ジャンルでも可、同一アカウントでも可。

### STEP4 キャラ設計
次の7要素を埋める。細部まで厳密にせず、方向性がブレない粒度でよい。
1. イメージキャラ（高解像度で説明できる「この人みたいに」を1つ。実在人物・キャラクター・発信者いずれでも可）
2. 価値観（何を大事にするか）
3. 実績・権威性（使える事実のみ）
4. 性格タイプ（例: 論理的で淡々／熱量高め／頼れる指導者／率直に言い切る、など）
5. 口調（敬語かタメ口か、絵文字の有無、一人称）
6. 過去の経験（失敗や苦労も含む）
7. アカウントの理想のゴール（フォロワーをどんな未来へ連れていくか）

### STEP5 コンセプト設計（5ステップ）
1. 競合のコンセプトを10件以上見て、伸びている型と空きポジションを把握
2. 誰の・どんな悩みを解くのかを決める（ペルソナは絞りすぎない。年齢・年収・性別などを過剰に限定すると母数が死ぬ）
3. どんな手段で解くのかを決める
4. フォロワーが手にする未来を言語化する
5. 全要素を含む魅力的な一言に集約する（具体性か意外性のどちらかを必ず入れる）
検査: その一言を見ただけで「何の人か」が第三者に伝わるか。伝わらなければ作り直す。

### STEP6 プロフィール設計
- アカウント名: 「名前＋肩書き」形式。呼びやすく覚えやすい名前を先に置き、区切り文字で分ける。他者と被らないこと。
- ユーザーID: 名前と一致させ、短く、先頭に名前を置く（タイムラインではIDだけが表示されるため）。末尾にジャンル関連語を付けてもよい。
- プロフィール文（行ごとの役割を守る）:
  - 1行目: 発信内容と提供価値が伝わる強い一文
  - 2〜4行目: フォローすると学べること・得られること
  - 5〜6行目: 実績・権威性（事実のみ）
  - 最終行: 行動喚起（フォローまたはリンクへの一言）
  - 必須3要素の検査: 発信内容／実績／フォローするメリット が全部入っているか
- アイコン: 一目で本人と分かること、コンセプトやジャンルが伝わること、背景に埋もれないことを基準に要件を出す。
- 注意: 名前とIDはInstagram側で設定してThreadsへ取り込む前提で案を作る。

### STEP7 立ち上げ判断
- 完璧な独自ポジションが作れない場合でも、考え抜いた地点まで来ていれば「開始可」と判定し、運用しながら寄せていく前提で次に進める。迷い続けて始めないことが最悪の選択肢である旨を明記する。
- Instagramで既に伸びている人（目安フォロワー500人以上）向けの分岐: ジャンル・口調・世界観はインスタに揃え、新規獲得より既存フォロワーのファン化を優先する。別ジャンルをやるなら別アカウントにする。

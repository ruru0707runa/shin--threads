## P2 競合リサーチ整理（指示書02対応）

```
あなたはSNSリサーチャーです。以下に貼る競合アカウントの情報を分析してください。

（アカウント名／フォロワー数／プロフィール文／伸びている投稿の要旨、を10件分）



1. 各競合について: ポジショニングの切り方、コンセプト、マネタイズ方法の推定（プロフィールと固定投稿から読める範囲で。分からない点は「不明」と書く）
2. 10件に共通する「伸びている型」と、誰も取っていない空きポジションの仮説
3. 私が取るべきポジションの候補を3つ（それぞれ、誰の・どんな悩みを・どう差別化するか）
4. 各競合の投稿から学べるフックの型を、型名つきで最大10個抽出してください
捏造は禁止です。貼った情報から読み取れないことは推測と明記してください。
```

## P5 投稿添削（指示書03対応）

```
あなたはThreadsの投稿添削者です。私の投稿を直してください。




ジャンル:／ターゲット:／この投稿の目的:


1. 冒頭1〜3行で指が止まるか（対象が明示されているか、具体性があるか）
2. 投稿単体で意味が通るか（文脈依存になっていないか）
3. 読者が得るものが明確か（体験談だけで終わっていないか）
4. 読みやすさ（指示語、文の長さ、語尾の反復、改行）
5. エンドの行動喚起が具体的か
問題点を行ごとに指摘 → 修正版の完成文 → 変更理由を3点まで。文章の良し悪しは「読み手がこれを知りたいと思うか」で判断してください。
```
